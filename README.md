# 🎬 Movie Library App

A Flutter-based movie library application developed as **Assignment 2** for the Software Development for Mobile Devices course.

## ✨ Features

- **Movie Collection:** Browse a collection of movies with their posters and details.
- **Search:** Search for movies by title or genre.
- **Grid & List Views:** Switch between grid and list layouts.
- **Movie Details:** View each movie's title, genre, release year, and rating.
- **Bookmarks:** Add or remove movies from bookmarks.
- **Shared Discount:** Tap the discount to decrease its value across all movie cards.
- **Dark Theme:** A cinematic dark interface with gold accents.

## 🛠️ Built With

- Flutter
- Dart
- Material Design
- Local image assets

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- An Android emulator or a connected device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/JohnGerges20/movie_library.git
   ```

2. Navigate to the project directory:

   ```bash
   cd movie_library
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
